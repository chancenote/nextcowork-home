Claude Dashboards는 연결된 데이터를 질문과 차트로 탐색하고, Claude Motion은 보고서의 핵심 메시지를 애니메이션으로 설명하는 기능입니다.

2026년 10월 8일 Anthropic이 두 기능을 베타로 공개했습니다. 중요한 변화는 AI가 텍스트 초안만 주는 것이 아니라, **판단을 돕는 데이터 화면과 전달을 돕는 움직이는 콘텐츠**까지 만들어 준다는 점입니다. 다만 두 기능의 사용 가능 플랜은 다르고, 어떤 수치를 믿고 공유할지는 여전히 사람이 결정해야 합니다.

## 두 기능의 차이는 무엇인가요?

| 비교 항목 | Claude Dashboards | Claude Motion |
|---|---|---|
| 핵심 질문 | 지금 데이터에서 무엇이 달라졌을까? | 이 내용을 어떻게 더 쉽게 설명할까? |
| 주요 입력 | 연결된 데이터 플랫폼·업무 앱 | 보고서·문장·차트·자료 |
| 주요 결과물 | 질문에 답하는 데이터 대시보드 | 짧은 설명 애니메이션 |
| 수정 방식 | 질문을 다시 하거나 차트의 조회 쿼리 확인 | 대화 또는 편집기에서 장면·문구·타이밍 수정 |
| 특히 유용한 장면 | 영업·운영 현황 탐색, 비교 보고 | 임원 브리핑, 교육, 제품·서비스 설명 |

Dashboards는 연결된 데이터에 조회 쿼리를 실행해 화면을 구성합니다. 차트가 무엇을 셌는지 확인하고 데이터의 마지막 갱신 시점도 볼 수 있습니다. Motion은 영상 생성 모델이 실제 사람이나 촬영 영상을 만들어 내는 방식이 아니라, 텍스트·차트·도형·이미지를 **코드로 움직이게 만드는 설명용 애니메이션**에 가깝습니다.

## 직접 넘기면서 이해하는 10장 카드뉴스

아래는 넥스트코웍에서 별도로 제작한 **움직이는 개념 설명 카드뉴스**입니다. 화면의 이전·다음 버튼, 자동 재생, 일시 정지, 키보드 방향키와 터치 넘기기를 이용해 보세요.

**중요:** 이 인터랙티브 자료와 별도 80초 영상은 Claude Motion에서 생성한 실제 작업물이 아닙니다. 공식 기능 설명을 기반으로 NEXT COWORK가 독립 제작한 시각 자료이며, 카드의 화면·차트는 기능 이해를 위한 예시입니다.

## 우리 회사 업무에서는 어떻게 활용할까요?

특별한 솔루션부터 만들 필요는 없습니다. **업무 질문 하나 + 확인 가능한 원천 데이터 하나 + 설명받을 대상 한 사람**으로 작게 시작하는 편이 좋습니다.

| 업무 | Dashboards에서 확인할 질문 | Motion으로 설명할 결과 |
|---|---|---|
| FlexOffice·공간 운영 | 이번 달 입주율·회의실 예약은 지난달과 어떻게 달라졌나? | 자산주용 30초 운영 현황 브리핑 |
| AI Campus 교육 운영 | 신청 경로별 참여·수료·후속 상담은 어떻게 이어지나? | 담당자·기관장용 교육 성과 요약 |
| B2B 영업 관리 | 고객 상담은 어느 단계에서 오래 머무르나? | 주간 영업회의용 핵심 변화 3가지 |

이 표는 **활용 시나리오 제안**입니다. 자동으로 모든 업무 데이터가 연결되는 것은 아닙니다. 실제 이용 가능 여부는 서비스 연결 지원, 권한, 데이터 품질, 조직의 보안 설정에 따라 달라집니다.

## 처음 실습할 때는 어떤 순서가 좋을까요?

1. **질문부터 정합니다.** “우리 매출을 보여줘”보다 “지난달 대비 이번 달 채널별 상담 전환율이 어떻게 달라졌는가?”처럼 비교 기준을 넣습니다.
2. **원천과 권한을 확인합니다.** 고객정보·재무정보는 조직의 승인된 연결과 적절한 접근 권한을 전제로 사용합니다.
3. **대시보드의 근거를 검증합니다.** 조회 쿼리, 집계 기간, 취소·환불 포함 여부, 데이터 갱신 시점을 확인합니다.
4. **설명할 사람을 정하고 영상화합니다.** 첫 화면은 문제, 다음은 변화, 마지막은 의사결정 또는 행동으로 구성해 봅니다.

가능한 조직이라면 먼저 하나의 작은 예시 데이터셋으로 Dashboards를 테스트하고, 검증한 결론을 Motion용 요약 자료로 넘기는 순서를 권합니다. 이 둘이 자동으로 한 번에 이어지는 단일 기능이라는 뜻은 아닙니다.

## 플랜별로 누구나 사용할 수 있나요?

**2026년 10월 16일 확인 기준**, Dashboards와 Motion은 모두 베타이지만 제공 범위가 다릅니다.

| Claude 플랜 | Dashboards | Motion |
|---|---|---|
| Free | 미제공 | 미제공 |
| Pro·Max | 제공 | 미제공 |
| Team | 제공 | 제공 |
| Enterprise | 관리자가 활성화하면 제공 | 관리자가 활성화하면 제공 |

Team의 Motion은 기본 활성화이며, Enterprise에서는 두 기능 모두 조직 소유자의 활성화가 필요합니다. 플랜별 사용량 한도가 적용되며, 복잡하고 긴 애니메이션은 일반 텍스트 응답보다 사용량을 더 소모할 수 있습니다. 최신 정책은 본문 아래의 Claude 공식 도움말을 다시 확인하세요.

## 바로 복사해 쓸 실무 요청문 3가지

### 1. 대시보드 — 공간 운영 현황

```text
연결된 공간 운영 데이터를 기준으로 이번 달과 지난달의
입주율, 회의실 이용 건수, 취소율을 비교하는 대시보드를 만들어 주세요.
집계 기간, 데이터 원천, 포함·제외 조건과 갱신 시점을
각 지표에서 확인할 수 있게 표시하고, 데이터가 부족하면 추측하지 마세요.
```

### 2. 대시보드 — 교육 프로그램 성과

```text
승인된 교육 신청·참석 데이터에서 프로그램별 신청 경로,
참석률, 후속 상담 전환 흐름을 비교해 주세요.
중복 참여자와 누락값 처리 기준을 설명하고,
특이한 수치가 나오면 확인할 질문을 함께 제시해 주세요.
```

### 3. 모션 — 대표자에게 보여줄 30초 설명

```text
첨부한 검증 완료 보고서를 바탕으로
의사결정자 대상 30초 설명 애니메이션을 만들어 주세요.
문제 제시 → 근거가 있는 변화 2가지 → 다음 행동 순으로 구성합니다.
숫자·문구는 원문에서만 가져오고, 출처 없는 성과는 만들지 마세요.
편집 가능한 텍스트·도표 중심으로 제작해 주세요.
```

## 도입 전에 확인할 체크리스트

- 데이터 원천과 연결 권한이 분명한가?
- 지표에 쓰인 집계 범위, 필터, 쿼리를 사람이 검증했는가?
- 공유 전 고객정보·재무정보·대외비가 노출되지 않는가?
- Motion 장면의 문구와 숫자가 승인된 원문과 일치하는가?
- 교육·임원보고용 최종 산출물에 책임 검토자가 있는가?

AI가 더 멋진 화면을 만드는 시대일수록 **올바른 숫자를 선택하고, 잘못된 해석을 걸러내며, 누가 무엇을 결정할지 설계하는 역량**이 더 중요해집니다.

## 자주 묻는 질문

### Claude Free 플랜에서도 Dashboards와 Motion을 쓸 수 있나요?

아닙니다. 2026년 10월 기준 두 베타 기능은 Free에 제공되지 않습니다. Dashboards는 Pro·Max·Team·Enterprise에서, Motion은 Team·Enterprise에서 제공됩니다.

### Motion이 실제 인물을 촬영한 것 같은 AI 영상을 만들어 주나요?

아닙니다. Claude Motion은 영상 생성 모델을 사용해 사실적인 촬영 장면이나 가상 인물을 생성하는 기능이 아닙니다. 코드로 텍스트·도표·이미지를 애니메이션화하며 MP4로 내보낼 수 있습니다.

### Dashboards가 만든 수치는 바로 경영회의에 써도 되나요?

중요한 의사결정 전에는 조회 쿼리와 데이터 원천, 집계 기준, 최신 갱신 시점, 예외값을 확인해야 합니다. AI가 그럴듯하게 보여주는 화면과 검증된 경영지표는 구분해야 합니다.
