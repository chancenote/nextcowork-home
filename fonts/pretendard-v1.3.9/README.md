## Common core-page subset

`common-core-e637a1095618.woff2` is a locally generated derivative containing the
737 source-supported characters in the body text of the nine core routes:
home, FlexOffice, AI Campus, Public, coaching, about, insights, contact and privacy.
Scripts, styles, templates, noscript content and HTML attributes are excluded.
The file is 153,668 bytes. Only the matching Unicode ranges use this last-declared
font face; all 92 original subsets remain available for other and future text.
Characters absent from the source font retain the existing system-font fallback.

The derivative retains the source variable glyphs, metrics, layout features and
weight axis. Its embedded family/PostScript names are changed to `NCW Core Sans`
to respect the upstream Reserved Font Name; the site's CSS alias remains
`Pretendard Variable`. Copyright and OFL credits remain embedded and in `OFL.txt`.

Reproduce from the repository root with Python and `fonttools[woff]` (generated
with fontTools 4.60.2):

```sh
curl -fsSL 'https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2' -o /tmp/PretendardVariable-1.3.9.woff2
python3 scripts/subset-fonts.py --source /tmp/PretendardVariable-1.3.9.woff2
```

The script verifies the source checksum, retains only supported characters,
checks the generated cmap against the CSS range and rejects output over 300 KB.
The filename includes the first 12 SHA-256 characters of the generated bytes;
regenerated font data therefore gets a new URL compatible with immutable caching.
The script updates only the common-font CSS rule and retains older font files so
cached stylesheets can continue to load their referenced asset.
Run it explicitly after relevant text changes; it is not part of the site build.
